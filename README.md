PyTorch Poker Cards Classifier CNN
A deep learning model for classifying playing cards using PyTorch and EfficientNet-B0.

Overview
This project implements a CNN to classify 53 different playing cards (52 standard deck cards + 1 joker). Built with PyTorch using transfer learning with EfficientNet-B0.

Features

- Transfer learning with pre-trained EfficientNet-B0
- Comprehensive accuracy analysis
- Confusion matrix analysis
- Multiple visualization tools
